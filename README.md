# Text Adventures

A C23 project for building text-based adventure games.

## Features
- Written in C23.
- Modular structure.

## Getting Started

### Prerequisites
- CMake 4.2 or higher.
- A C23 compatible compiler (e.g., GCC 13+ or Clang 18+).

### Building
```bash
mkdir build
cd build
cmake ..
make
```

### Running
```bash
./text_adventures
```
